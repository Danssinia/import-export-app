
# Import Export App – Backend Prototype

A backend prototype developed with NestJS and TypeScript to explore server-side development concepts for an import and export management platform.

## 📌 Overview

Import Export App is an experimental backend project associated with the broader Import Export platform.

This repository serves as a development sandbox for exploring backend architecture, application structure, and server-side functionality using NestJS.

> **Project Status:** Experimental / Prototype  
> This repository is intended for learning, experimentation, and development rather than production use.

## 🚀 Tech Stack

| Technology | Purpose |
|------------|---------|
| NestJS | Backend application framework |
| Node.js | JavaScript runtime |
| TypeScript | Application development |
| npm | Dependency management |

## ✨ Project Objectives

- Explore backend development using NestJS.
- Experiment with modular server-side architecture.
- Practice TypeScript-based backend development.
- Establish a foundation for testing backend concepts.
- Gain experience with development and testing workflows.

## 📦 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Danssinia/import-export-app.git
```

Navigate to the project directory:

```bash
cd import-export-app
```

Install dependencies:

```bash
npm install
```

## ▶️ Running the Application

### Development Mode

```bash
npm run start
```

### Watch Mode

```bash
npm run start:dev
```

### Production Mode

```bash
npm run build
npm run start:prod
```

## 🧪 Testing

The project includes standard NestJS testing scripts.

### Unit Tests

```bash
npm run test
```

### End-to-End Tests

```bash
npm run test:e2e
```

### Test Coverage

```bash
npm run test:cov
```
